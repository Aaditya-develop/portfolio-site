AI · Agentic RAG

SEC 10-K Research Assistant

A multi-agent research assistant that answers questions about company annual reports. A LangGraph orchestrator decides whether each question needs the filings, live web data, or neither, then hands off to specialised retriever, search and writer agents.

  • Hybrid retrieval: ChromaDB vector search (OpenAI text-embedding-3-small) merged with BM25 keyword ranking, so exact figures and table rows aren't missed.
  • Self-checking writer: GPT-4o drafts an answer, a second pass checks it against the source chunks and regenerates when it isn't grounded.
  • Measured, not guessed: a RAGAS suite of 10-K questions fails the run if faithfulness drops below 0.90 or answer relevancy below 0.85.
  • Production plumbing: FastAPI /ask endpoint returning cited sources, Langfuse tracing, and CI/CD to Azure App Service via GitHub Actions.

Board & Brush Timesheet App

A full-stack mobile app built for Board & Brush Creative Studio to replace paper timesheets. Employees log their shifts in seconds; managers get one place to run the team and pull hour reports for payroll.

  • Role-based access: separate employee and admin experiences from one login, with secure password changes and resets.
  • Time tracking: record date, start and end time; hours are calculated and stored automatically.
  • Admin tools: add and remove employees, fix or delete timesheet entries, and generate reports per employee or date range.
  • Supabase + PostgreSQL backend: relational schema linking users and time logs, with server-side RPC functions for fast reporting. Built to support 10+ employees.
